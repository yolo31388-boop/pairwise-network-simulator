# 网络延迟与丢包模拟系统

## 项目描述

网络延迟与丢包模拟系统的bug修复项目。核心模块 `network/network_simulator.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 延迟模拟只设变量不实际延迟数据包
- 丢包模拟完全没做设置30%实际0%
- 带宽限制完全没做设置1Mbps实际100Mbps
- 抖动模拟完全没做延迟永远固定
- 网络配置只有预设不能自定义保存切换

## 运行测试

```bash
python -m pytest tests/test_network_simulator.py -q
```

修复目标：所有 14 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
